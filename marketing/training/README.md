# Downhole Studio training video

A narrated, captioned walkthrough of the complete workflow in the real application. It runs about 6 minutes at 1920 × 1080, H.264/AAC, and is shipped in the client package with an `.srt` subtitle file.

| File | Role |
|---|---|
| `storyboard.json` | Narration per segment (spelled for the voice, e.g. "S E G two"), chapters and the shots shown during each segment |
| `common.py` | Paths, and the rules that turn the spoken text into written captions |
| `narrate.py` | Offline Kokoro voice (`af_heart`, Apache-2.0 model), CPU only |
| `../../tests/DownholeStudio.UiTests/TrainingCapture.cs` | Drives the real application through the storyboard and records, for each shot, a frame, the screen point that is clicked to reach it, and optional zoom regions |
| `render.py` | Builds every frame: the pointer moves to and clicks each control, shots cross-fade, detail shots zoom in, and chapter cards and a caption band are added. Writes the MP4, SRT, chapter list and poster |

The data is a synthetic survey generated by Downhole Studio (`TriggerErrors` dataset, 32 depths). No customer data is filmed. The commands are in [BUILD.md](../../BUILD.md#customer-documents-training-video-and-client-package). Update `version` in `storyboard.json` for a new release, and check a few rendered frames before publishing.
