# Download Downhole Studio

**[⬇ Download DownholeStudio-Setup.exe](https://github.com/omerozgul11/ql-downhole/raw/main/download/DownholeStudio-Setup.exe)** — the Windows installer (64-bit, Windows 10 21H2 or later / Windows 11).

Run the downloaded file to install. No administrator rights are needed. If Windows SmartScreen shows *Windows protected your PC*, choose **More info → Run anyway**.

The SHA-256 checksum of the installer is in [DownholeStudio-Setup.exe.sha256](DownholeStudio-Setup.exe.sha256). To verify it in PowerShell:

```powershell
Get-FileHash .\DownholeStudio-Setup.exe -Algorithm SHA256
```
